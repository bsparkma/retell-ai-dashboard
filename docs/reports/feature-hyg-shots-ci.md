### Render check, not pixel comparison

CI checks that the page renders. It does not compare pixels. Each shot test waits in
jsdom for the testids it needs (`findByTestId`) and writes the markup to `tests/.shots/`,
which is gitignored. CI starts no browser and compares no PNGs. The PNGs in
`docs/screenshots/` are still regenerated by hand with `scripts/shoot-hyg.mjs`, because
headless Chrome's font rasterisation differs from one runner to the next.

### The skip guard

A suite that skipped still exits 0. If someone renamed `HYG_SHOTS` or changed the
`skipIf`, the step would stay green while running nothing, which is the same silent rot
this slice is meant to end. So the step writes vitest's JSON report to
`$RUNNER_TEMP/hyg-shots-result.json` and fails if any of these hold: total is 0, any test
was skipped or todo, or passed ≠ total.

Checked locally: with `HYG_SHOTS=1` the result was `total 22 passed 22 skipped 0` and
exit 0. With `HYG_SHOTS=0` it was `total 22 passed 0 skipped 22`, printed
`perio shots suite did not fully run`, and exited 1.
